# 08. AI COLLABORATION (KODE framework)


## Objetivo
Establecer las directrices de colaboración conjunta entre ingenieros de software humanos y agentes o asistentes de Inteligencia Artificial en el desarrollo de JATapp, bajo el ecosistema KODE donde "El conocimiento guía el proyecto y las personas guían el conocimiento".

## Tabla de Contenido
1. Objetivo
2. Filosofía de Colaboración KODE (Human-Centered AI)
3. Roles de las Inteligencias Artificiales en el Ciclo de Desarrollo
4. Flujo de Trabajo y Sincronización Humano-IA
5. Directivas de Trazabilidad y Guardado de Prompts
6. Pendiente de completar

## Pendiente de completar
*   Definición de roles y responsabilidades de las IAs como agentes de soporte.
*   Detalle del flujo de trabajo interactivo manteniendo la soberanía de decisión humana.
*   Detalles de las directivas de trazabilidad de prompts y respuestas oficiales bajo KODE (PRM y STM).

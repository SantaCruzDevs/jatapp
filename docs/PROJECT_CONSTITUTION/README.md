# KODE Constitution & Governance — JATapp

## Objetivo
Servir como la base fundacional de gobernanza del ecosistema **KODE** (Knowledge-Oriented Development Ecosystem) adaptada para el proyecto JATapp, oficializando su adopción y marco regulatorio.

## Alcance
Define los principios constitucionales de gobernanza, la propiedad intelectual de la metodología, los roles de colaboración humano-IA y las decisiones aprobadas.
